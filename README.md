# NAME

M'TAG - Tag audio files based on filenames

# SYNOPSIS

    m-tag FILEPATH [-r] [-t] [-v] [-s] [-j] [-c] [-f SPLITON FIELDS | -f FIELD]

# DESCRIPTION

M'TAG is a short program that takes a file directory as a command line argument
and tags every compatible audio file within the directory that has the naming
convention "Title - Artist.filetype" (alternate naming conventions can be
specified) while ignoring all other files.

Compatible with .MP3, .OGG, .WAV, and .FLAC filetypes.

## INSTALLATION

(Requires a Java JDK, the Clojure Core, and [Leiningen])

Download the source from [Github] and run

    lein uberjar

anywhere within the project to generate a standalone .JAR file in
`/target/uberjar`.  This .JAR file is now completely independent of
the project and can be moved or run at will.

## USAGE

### AS A .JAR

The .JAR file generated by leiningen can be run as all .JAR files are:

    java -jar m-tag-1.0.0-standalone.jar FILEPATH [OPTIONS]

### AS A LEININGEN PROJECT

Leiningen can be used to run M'TAG anywhere within the project:

    lein run FILEPATH [OPTIONS]

# OPTIONS

M'TAG does not have a proper argument parser, so options MUST come after the
filepath and they must all be separate flags (e.g. `-r -j` and not `-rj`).

`-r`
:   Recursively operate on subfolders.

`-t`
:   Execute a test run without edits, printing files and CURRENT tags.

`-v`
:   Print tag information for each file (implied in `-t`).

`-s`
:   Silence errors.

`-j`
:   Print the JAudioTagger log.

`-c`
:   Clear tags.

`-f SPLITON FIELDS` or `-f FIELD`
:   Change the expected filename format; `SPLITON` is a regular expression used
    to split the filename, while `FIELDS` and `FIELD` are the tag fields in
    order of appearance.  Available fields are

    * track
    * album
    * disc
    * album-artist
    * num-discs
    * title
    * year
    * num-tracks
    * artist

    If `-f` if supplied, it must be the final option.
