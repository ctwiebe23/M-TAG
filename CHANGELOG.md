# Changelog

All notable changes to this project will be documented in this file. This
change log follows the conventions of [keepachangelog.com].

Uses Semantic Versioning.

## 0.6.1 - 2026-04-23

### Added

- A proper README file

## 0.6.0 - 2024-08-20

### Changed

- Major file restructuring and code refactoring, no change in usage

## 0.5.0 - 2024-02-22

### Added

- Option to clear tags

### Fixed

- Printed audio tags are now properly trimmed

## 0.4.0 - 2024-01-19

### Added

- Option to enable JAudioTagger log

### Changed

- Silenced the JAudioTagger log by default

## 0.3.0 - 2024-01-10

### Added

- Format option

### Fixed

- Now properly shrinks tag size when re-tagging a file that previously had a
  larger tag

## 0.2.0 - 2024-01-04

### Added

- Support for .ogg, .wav, and .flac files
- Test run option
- Recursive option
- Silent option
- Verbose option

## 0.1.0 - 2023-12-28

### Added

- Project start
- Support for .mp3 files
